# AI Animation Studio (ស្ទូឌីយោបង្កើតវីដេអូ Animation & សំឡេង AI)

កម្មវិធីកុំព្យូទ័រ Windows សម្រាប់ផលិតវីដេអូ Animation រឿងនិទាន តុក្កតា និងគំនូរជីវចល ដោយស្វ័យប្រវត្តិតាមរយៈ AI (Text-to-Video Story Generator)។

---

## 🌟 លក្ខណៈពិសេសចម្បងៗ (Key Features)

1. **សាច់រឿង និងប្លង់ Scene ដោយ AI:**
   - ប្រើ **Google Gemini API (Free Tier)** ដើម្បីតែងសាច់រឿង បែងចែកប្លង់ Scene និងបង្កើត Prompt រូបភាព។
   - គាំទ្រជម្រើស **Groq API** ជា Fallback ផងដែរ។

2. **រូបភាព AI គុណភាពខ្ពស់ (100% Free - គ្មាន Key):**
   - ភ្ជាប់ដោយស្វ័យប្រវត្តិជាមួយ **Pollinations.ai (FLUX / Turbo)**។
   - គាំទ្ររចនាប័ទ្មរូបភាពច្រើនបែប៖
     - ✨ *3D Disney Pixar Animation*
     - 🌸 *2D Anime / Manga Style*
     - 💥 *Comic Book / Graphic Novel*
     - 🎬 *Cinematic Realistic Movie*
     - 🧸 *Cute Chibi 3D Miniature*
     - 🎨 *Watercolor Fairy Tale*

3. **សំឡេងនិយាយខ្មែរធម្មជាតិ (100% Free - Edge-TTS):**
   - សំឡេងលោក **ពិសិដ្ឋ (ប្រុស)** និងកញ្ញា **ស្រីមុំ (ស្រី)** ឥតគិតថ្លៃ គ្មានដែនកំណត់។
   - អាចកែសម្រួលល្បឿននិយាយបាន (+/- % speed)។

4. **ចលនាកាមេរ៉ា & អក្សររត់ស្វ័យប្រវត្តិ (FFmpeg 2.5D Engine):**
   - ធ្វើឱ្យរូបភាពមានចលនាបែបភាពយន្ត៖ *Zoom In, Zoom Out, Pan Left, Pan Right*។
   - បង្កើត និងដុតអក្សររត់ខ្មែរ (Burned Subtitles) ស្អាត ច្បាស់ មិនបាក់ជើងអក្សរ (Leelawadee UI / Khmer OS font)។

5. **ទម្រង់វីដេអូ (Aspect Ratio):**
   - 📱 **បញ្ឈរ 9:16:** សម្រាប់ TikTok, Facebook Reels, YouTube Shorts។
   - 🖥️ **ផ្ដេក 16:9:** សម្រាប់ YouTube Long Videos។

6. **របៀបដំណើរការ (Workflow Modes):**
   - 🚀 **1-Click Full Auto:** បញ្ចូលតែប្រធានបទ ចុចតែមួយប៊ូតុង ចេញជាវីដេអូសម្រេចតែម្តង!
   - 📝 **Studio Editor Mode:** អាចមើល Preview និងចូលកែសម្រួលរូបភាព អត្ថបទសម្រាយ សំឡេង ឬចលនាតាម Scene នីមួយៗតាមចិត្ត។

## 🚀 របៀបចាប់ផ្តើមដំណើរការ (Quick Start)

### ១. ដំណើរការកម្មវិធី
ចុច Double-click លើ File **`run_app.bat`** ឬដំណើរការតាម Command:
```bash
cd d:\project_pos\tools\tools-ai-animation
python main.py
```

### ២. បញ្ចូល API Key ក្នុង Settings (ធ្វើតែម្តងគត់)
1. បើកកម្មវិធី រួចចុចលើប៊ូតុង **⚙️ ការកំណត់ (Settings)** នៅជ្រុងខាងស្តាំខាងលើ។
2. ចុចលើតំណភ្ជាប់ **🔗 យក Key Free (Google AI Studio)** ឬចូលទៅកាន់ [aistudio.google.com](https://aistudio.google.com/) ដើម្បីយក Gemini API Key ឥតគិតថ្លៃ។
3. បញ្ចូល Key ក្នុងប្រអប់ Gemini API Key រួចចុច **"តេស្ត Key (Test)"**។
4. ចុច **"រក្សាទុក (Save Settings)"** ជាការស្រេច!
